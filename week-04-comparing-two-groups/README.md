# Week 4 — Comparing Two Groups

## Learning outcomes

By the end of this week you should be able to:

1. State a testable hypothesis about a difference between two groups.
2. Inspect an outcome variable and decide, with stated evidence, whether a
   parametric or non-parametric comparison is appropriate.
3. Run and interpret an independent-samples *t*-test and a Mann–Whitney *U* test.
4. Run and interpret a chi-square test of independence between two categorical
   variables.
5. Report an effect size alongside every test and describe its magnitude.
6. Write the result in the module's reporting convention, with the statistics
   generated from the analysis.

# Unit 5 — Comparing More Than Two Groups

## Learning outcomes

By the end of this unit you should be able to:

1. Explain why running a *t*-test on every pair of groups inflates the
   familywise error rate, and what an omnibus test does instead.
2. Explain how one-way ANOVA compares means through variance: the partition of
   the sums of squares, the *F*-ratio and its two degrees of freedom.
3. Check ANOVA's assumptions within groups, visually first, and describe
   variance heterogeneity without gating the analysis on a variance test.
4. Run and interpret Welch's one-way ANOVA and a Games–Howell follow-up.
5. Run and interpret a Kruskal–Wallis test, with Dunn's follow-up under a named
   correction for multiple comparisons.
6. Report ω² (with η²), or η²(*H*), alongside every omnibus test, describe its
   magnitude, and generate the report from the analysis.
7. Recode an ordinal variable stored as text, and show by counting that the
   recode lost nothing.

# Week 2 — Describing Data

## Learning outcomes

By the end of this week you should be able to:

1. Distinguish a parameter from a statistic, and a standard deviation from a
   standard error.
2. Explain sampling variation and what the sampling distribution of a statistic
   is.
3. State the Central Limit Theorem accurately, and say what it does **not**
   claim.
4. Use the properties of the normal distribution, including the empirical rule,
   to sanity-check a summary.
5. Convert a value to a *z*-score and turn it into a tail probability.
6. Describe a continuous variable's centre, spread **and** shape, and choose the
   summaries that suit its shape.
7. Apply the 1.5 × IQR fence and decide what a flagged value actually means.
8. Choose the right plot for a variable, and explain what the bin width or
   bandwidth is doing to it.
9. Write a dataset description a reader could act on.

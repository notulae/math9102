# Week 1 — Fundamentals

## Learning outcomes

By the end of this week you should be able to:

1. State a question, a theory and a hypothesis, and name the variables they
   imply.
2. Assign a level of measurement to any variable and defend the choice.
3. Say whether a given dataset is a population or a sample for a given question,
   and explain why it matters.
4. Load a dataset by name, and establish what is in it.
5. Describe a categorical variable with counts and percentages, stating which
   way it was percentaged.
6. Describe a continuous variable with a centre, a spread and a statement about
   shape, and justify which centre and which spread.
7. Quantify what listwise deletion would cost the analysis they intend to run.
8. Interrogate a published statistic: who was measured, what were they asked,
   what is the denominator.
